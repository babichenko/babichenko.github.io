# Anna Babichenko

This is the personal website for Anna Babichenko, an incoming Computer Science transfer student at California State University, Fullerton with a background in mathematics.

The site is a place for project writeups, blog posts, resume details, and notes on learning, building, accessibility, and computer science.

Visit the website: [babichenko.github.io](https://babichenko.github.io/)

## About This Site

This website is built with [Jekyll](https://jekyllrb.com/) and hosted with GitHub Pages.

It uses the [Academic Pages](https://academicpages.github.io/) template as a starting point, with custom content and styling for Anna's personal site.

## Repository

This repository contains the source files for the website, including pages, posts, site configuration, styles, and assets.
